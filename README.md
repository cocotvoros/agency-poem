# agency-poem

Entry for make.fun `agency-poem-01` — "Write the best poem about agency".

A program (`main.ts`, Node 22, standard library only) that writes one poem
to `/output/entry.txt`: at 2:47 a.m. a speaker orders their agent to send a
resignation written in rage; the agent holds it until morning, and the power
to choose comes back with the daylight.

Run it:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
